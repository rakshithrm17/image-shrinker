# Design System — Image Shrinker

This design system provides the **visual identity** for Image Shrinker.  
It ensures consistency across UI development and future feature expansion.

---

# 🎨 1. Color Palette

## Primary Colors
| Name | Hex | Usage |
|------|------|--------|
| Primary Blue | `#0B5CFF` | Main buttons, highlights |
| Blue Light | `#3D7BFF` | Hover states, accents |

## Neutral Colors
| Name | Hex | Usage |
|------|------|--------|
| Background | `#F7F9FC` | App background |
| Dark Text | `#1A1A1A` | Headings & primary text |
| Gray Text | `#707070` | Secondary text |
| Border Gray | `#D8D8D8` | Component borders |

## Status Colors
| Name | Hex |
|------|------|
| Success | `#28C76F` |
| Warning | `#FF9F43` |
| Error | `#EA5455` |

---

# 🔤 2. Typography

Use modern, web-safe fonts:

### **Primary Font:** Inter  
Fallbacks: `system-ui`, `Segoe UI`, `Roboto`, `Helvetica`

### Font Sizes
- Heading 1: **28px**
- Heading 2: **20px**
- Body Text: **16px**
- Small Text: **13–14px**
- Footer / Disclaimer: **12px**

### Font Weights
- **700** Bold — Headings  
- **500** Medium — Buttons  
- **400** Regular — Body text  

---

# 📏 3. Spacing Scale

Use consistent spacing values:

| Name | Value |
|------|--------|
| XS | 4px |
| S | 8px |
| M | 16px |
| L | 24px |
| XL | 32px |

---

# 📦 4. Components

## Buttons
**Primary Button**
- Background: `#0B5CFF`
- Text: white
- Border-radius: 8px
- Hover: darker blue
- Padding: 12px 20px

**Secondary Button**
- Border: `#0B5CFF` solid 1px
- Background: white
- Text: blue

---

## Inputs (File upload)
- Border: dashed `#D8D8D8`
- Border-radius: 12px
- Height: 140px large rectangle
- Hover: border becomes blue
- Text centered

---

## Toggle Buttons (Modes)
Segmented control with 3 options:
- Preserve Zoom (default)
- Downscale
- Lossless

Style:
- Selected tab background: blue
- Unselected: light grey
- Rounded corners: pill-shaped (30px radius)

---

## Preview Cards
For before/after preview:
- Border: `#D8D8D8`
- Background: white
- Padding: 12px
- Zoom controls as small rounded buttons

---

# 📘 5. Shadows & Radiuses

### Shadows
- Light UI shadow:  
  `0px 4px 10px rgba(0, 0, 0, 0.04)`

### Border Radiuses
- Buttons: `8px`
- Cards: `12px`
- Upload box: `12–16px`
