# Wireframes — Image Shrinker

Wireframes represent the **basic structure and layout** of the UI without colors or detailed styling.  
They help visualize how users will interact with the application.

Below is the MVP wireframe layout drawn in ASCII for clarity.

---

## Notes from Wireframe
- Everything fits on one scrollable page.
- The user flow is always:
  **Upload → Select Options → Preview → Download**
- Important information (file size saved, zoom view, mode choice) is visible.
- Mobile design uses stacked layout (vertical first).
